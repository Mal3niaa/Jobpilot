# JobPilot

> AI-powered job search assistant — analyze opportunities, track applications, and prepare for interviews.

**Status:** 🚧 In development — Phase 2 (Project Initialization)

## Overview

JobPilot helps developers manage their job search in one place:
upload a CV once, add jobs, get explainable AI analysis, track applications.

See [docs/CONCEPT.md](docs/CONCEPT.md) for full product concept.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JS, Chart.js
- **Backend:** Node.js, Express, PostgreSQL
- **AI:** OpenAI API (via n8n or direct)
- **Auth:** JWT + bcrypt
